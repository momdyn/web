Parameter
=========

A parameter is a named constant, such as a length, a mass or a spring stiffness, that you define once and reuse in other components.

.. diagram:: A parameter named l with value 1 and description length, listed in the report's symbols tab

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Key to be used when referencing this parameter in the mechanism.p dictionary. Can be entered using LaTeX symbol formatting, i.e. \theta yields θ, etc
   value | numeric | 0 | depends on use | Constant value for the parameter
   description | str | '' | — | Description of the parameter

Sign conventions & notes
------------------------

* A parameter keeps the same value for the whole simulation. For a quantity that changes with time, use a `generalized coordinate <generalized_coordinate.html>`__.
* Names accept LaTeX-style input: ``\theta`` becomes θ and ``\omega`` becomes ω.
* Bodies, joints and spring-dampers create their own parameters (for example the mass of a particle named ``bob`` is ``m_bob``).
