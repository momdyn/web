Point
=====

A point is a location in space, defined by a vector from another point; its velocity and acceleration follow from the motion of the mechanism.

.. diagram:: A blue sphere marking a point at the end of a vector in the diagram view

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Key to be used when referencing this point.
   ref_point_key | str | 'origin' | — | Key of the point from which the created points position will be measured.
   vector_key | str | None | — | Key of the vector used to define the position of the created point relative to the reference point

Equations
---------

The new point P is offset from the reference point Q by the vector:

.. math::

   \mathbf{r}_{P/O} = \mathbf{r}_{Q/O} + \mathbf{r}

Sign conventions & notes
------------------------

* The default reference point is ``origin``, which is fixed in the inertial frame.
* Bodies, loads and sensors attach to points, so any location you want to put a mass, force or sensor needs a point.
