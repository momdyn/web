Vector
======

A vector is an arrow whose x, y and z components are measured along the axes of a chosen frame.

.. diagram:: A gray line from the origin to a blue point, representing a vector with its start at the origin

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Key to be used when referencing this vector in the mechanism.vectors dictionary.
   ref_point_key | str | 'origin' | — | Key of the point used to mark the start of the vector.
   ref_frame_key | str | 'inertial' | — | Key of the frame in which the x, y, z components are measured.
   x | str | 0 | — | Key of the parameter or generalized coordinate for distance in x- component of the reference frame
   y | str | 0 | — | Key of the parameter or generalized coordinate for distance in y- component of the reference frame
   z | str | 0 | — | Key of the parameter or generalized coordinate for distance in z- component of the reference frame

Equations
---------

The vector is the sum of its components along the basis vectors of the reference frame:

.. math::

   \mathbf{r} = x\,\mathbf{e}_x + y\,\mathbf{e}_y + z\,\mathbf{e}_z

Sign conventions & notes
------------------------

* Each of ``x``, ``y`` and ``z`` is the name of a parameter or generalized coordinate (or a number). That symbol supplies the length, so its units are lengths.
* ``ref_point_key`` marks where the vector starts in the diagram. To place a point with the vector, create a `point <point.html>`__.
* In the pendulum tutorial the vector ``r`` has ``x = l`` in the rotated frame ``E``.
