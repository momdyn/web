Frame
=====

A frame is a set of three perpendicular unit vectors that is rotated by up to three Euler angles relative to another frame.

.. diagram:: A rotated reference frame drawn with red, green and blue axes next to the inertial frame

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   ref_point_key | str | 'origin' | — | Name of the point where the frame will be centered, for visualization in the diagram.
   ref_frame_key | str | 'inertial' | — | Name of the reference frame from which the relative orientation angles are measured.

Equations
---------

A single rotation θ about the z-axis of a frame with unit vectors n gives a new frame with unit vectors e:

.. math::

   \mathbf{e}_x = \cos\theta\,\mathbf{n}_x + \sin\theta\,\mathbf{n}_y, \qquad \mathbf{e}_y = -\sin\theta\,\mathbf{n}_x + \cos\theta\,\mathbf{n}_y, \qquad \mathbf{e}_z = \mathbf{n}_z

Sign conventions & notes
------------------------

* Angles are in radians and positive by the right-hand rule. Each angle can be a number or the name of a parameter or generalized coordinate.
* ``rotation_sequence`` such as ``'ZYX'`` means: rotate ``first_angle`` about the Z-axis of the reference frame, ``second_angle`` about the new Y-axis, then ``third_angle`` about the newest X-axis.
* ``ref_point_key`` only sets where the frame is drawn in the diagram. It does not change the physics.
