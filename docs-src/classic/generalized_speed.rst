Generalized Speed
=================

A generalized speed is a time-varying symbol that describes the motion of the mechanism; by default it is the time derivative of a generalized coordinate.

.. diagram:: A generalized speed dialog with a name, an equates-to expression and an initial value

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Key to be used when referencing this coordinate in the mechanism.q dictionary. Can be entered using LaTeX symbol formatting, i.e. \omega yields ω, etc.
   equates_to | str | None | — | Equation representing terms in the point velocity or frame angular velocity equations that will be replaced by this generalized speed.
   initial | numeric | 0 | m/s or rad/s | Initial value for the generalized speed
   description | str | None | — | Description of the generalized speed

Equations
---------

By default the speed is the derivative of its coordinate:

.. math::

   u_i = \dot{q}_i

In general, the coordinate rates follow from the speeds through the kinematic differential equations:

.. math::

   \dot{\mathbf{q}} = \mathbf{f}(\mathbf{q}, \mathbf{u})

Sign conventions & notes
------------------------

* Choosing other speeds can give a more compact set of equations. For a free rigid body, a common choice is the velocity components in the body-fixed frame.
* ``equates_to`` names the terms in a point velocity or a frame angular velocity that this speed replaces.
