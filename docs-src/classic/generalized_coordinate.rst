Generalized Coordinate
======================

A generalized coordinate is a time-varying symbol that describes one degree of freedom of the mechanism, such as an angle or a displacement.

.. diagram:: A generalized coordinate dialog with name theta, initial value 1 and description angle

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Key to be used when referencing this coordinate in the mechanism.q dictionary. Can be entered using LaTeX symbol formatting, i.e. \theta yields θ, etc
   initial | numeric | 0 | m or rad | Initial value for the generalized coordinate
   description | str | None | — | Description of the generalized coordinate

Equations
---------

The coordinate is a function of time, and its initial value sets the starting configuration:

.. math::

   q = q(t), \qquad q(0) = q_0

Sign conventions & notes
------------------------

* Each generalized coordinate adds one degree of freedom to the equations of motion.
* Names accept LaTeX-style input: ``\theta`` becomes θ. Select the coordinate by name in frame and vector dialogs, for example ``θ(t)``.
* The Joints interface creates coordinates for you (the revolute joint ``E`` creates θ\_E).
