Translational Spring
====================

A translational spring/damper induces an attractive force between two points that is collinear with a vector drawn from the start to end point. The force magnitude is

F = k (x - e) + c x'

where k is the spring stiffness, x is the distance between the two points, e is an equilibrium length of the spring, c is the damping constant, and x' is the differential speed between the two points.

Keyword arguments
-----------------

.. param:: start_point
   :type: str

   Key for the first point.

.. param:: end_point
   :type: str

   Key for the second point.

.. param:: k
   :type: numeric

   Spring stiffness constant.

.. param:: c
   :type: numeric

   Damping constant.

.. param:: equilibrium
   :type: numeric

   Equilibrium length of the spring.
