Actuated Moment
===============

An actuated moment acts with equal and opposite magnitude on two frames, like a motor turning one link against another.

.. diagram:: Equal and opposite moment arrows on two frames, like a motor between two links

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Name given to the moment.
   ref_frame_key | str | 'inertial' | — | Reference frame in which the vector components of the moment are defined.
   first_frame_key | str | 'inertial' | — | First frame upon which the moment acts.
   second_frame_key | str | 'inertial' | — | Second frame upon which the moment acts, with negative magnitude.
   moment | numeric | 0 | N·m | Moment magnitude.
   x | numeric | 0 | — | X-component of the vector about which the moment is defined.
   y | numeric | 0 | — | Y-component of the vector about which the moment is defined.
   z | numeric | 0 | — | Z-component of the vector about which the moment is defined.

Equations
---------

Moment on the first frame and on the second frame, with magnitude M about the unit vector u:

.. math::

   \mathbf{M}_{1} = M\,\hat{\mathbf{u}}, \qquad \mathbf{M}_{2} = -M\,\hat{\mathbf{u}}

Sign conventions & notes
------------------------

* The direction is set by the components x, y and z in ``ref_frame_key``. TODO: confirm that the components are normalized, so that only ``force`` (or ``moment``) sets the magnitude.
* Use it between the two frames on either side of a revolute joint to model a motor or an actuator.
