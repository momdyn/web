Universal
=========

A universal joint creates a frame that is rotated relative to an existing frame using a two angles to define its orientation.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)

.. param:: ref_point_key
   :type: str

   Start point from which the vector component of the joint is defined

.. param:: ref_frame_key
   :type: str

   Reference frame in which the translational and rotational displacement components are defined

.. param:: rotation_pair
   :type: str

   'XY', 'YX', 'YZ', 'ZY', 'ZX', or 'XZ', represents a two angle rotation sequence

.. param:: initial_r0
   :type: numeric

   Initial value for the 0th rotation angle in the Euler sequence

.. param:: initial_r1
   :type: numeric

   Initial value for the 1st rotation angle in the Euler sequence

.. param:: rate_r0
   :type: numeric

   Initial value for angular rotation rate of the 0th angle

.. param:: rate_r1
   :type: numeric

   Initial value for angular rotation rate of the 1st angle Optional stiffness, damping, and equilibrium coefficients can be used to include rotational spring-damper physics in the joint.

.. param:: kr0
   :type: numeric

   Stiffness corresponding to the 0th rotation angle in the Euler sequence

.. param:: kr1
   :type: numeric

   Stiffness corresponding to the 1st rotation angle in the Euler sequence

.. param:: cr0
   :type: numeric

   Damping corresponding to the angular rotation rate about the x-axis of the created frame

.. param:: cr1
   :type: numeric

   Stiffness corresponding to the angular rotation rate about the y-axis of the created frame

.. param:: equilibrium_r0
   :type: numeric

   Equilibrium corresponding to the 0th rotation angle in the Euler sequence

.. param:: equilibrium_r1
   :type: numeric

   Equilibrium corresponding to the 1st rotation angle in the Euler sequence
