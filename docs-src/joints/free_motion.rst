Free Motion
===========

A free motion joint creates a point that is translated by three component coordinates defined in the reference frame, and a frame that is rotated relative to an existing frame using a quaternion to define its orientation. Initial quaternion values are defined using an equivalent Euler angle sequence.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)

.. param:: ref_point_key
   :type: str

   Start point from which the vector component of the joint is defined

.. param:: ref_frame_key
   :type: str

   Reference frame in which the translational and rotational displacement components are defined

.. param:: rotation_sequence
   :type: str

   'ZYX', 'XYZ', 'ZXZ', 'ZYZ', 'XYX', or 'XZX', represents the Euler angle sequence used for defining equivalent initial quaternion states

.. param:: initial_t0
   :type: numeric

   Initial value for displacement in the x-axis of the reference frame

.. param:: initial_t1
   :type: numeric

.. param:: initial_t2

   Initial value for displacement in the z-axis of the reference frame

.. param:: initial_r0

   Initial value for the 0th rotation angle in the Euler sequence

.. param:: initial_r1
   :type: numeric

.. param:: initial_r2
   :type: numeric

   Initial value for the 2nd rotation angle in the Euler sequence

.. param:: rate_t0
