Free Motion
===========

A free motion joint gives a frame all six degrees of freedom: three translations and a free orientation, like a rigid body floating in space.

.. image:: ../img/freemotion.jpg
   :width: 400
   :alt: A free motion joint: a frame that can translate along all three axes and take any orientation

Equations
---------

Position of the new point relative to the start point A:

.. math::

   \mathbf{r}_{B/A} = t_0\,\mathbf{e}_x + t_1\,\mathbf{e}_y + t_2\,\mathbf{e}_z

Orientation is a unit quaternion:

.. math::

   q_0^2 + q_1^2 + q_2^2 + q_3^2 = 1

Sign conventions & notes
------------------------

* ``is_form`` is ``'degree of freedom'`` (the value is a time-varying coordinate that the simulation solves for) or ``'constant'`` (the value is fixed).
* ``initial_r0``, ``initial_r1`` and ``initial_r2`` give the starting orientation as an equivalent Euler angle sequence (``rotation_sequence``).
* The ``rate_t*`` values are velocity components, and the ``rate_r*`` values are angular velocity components, about the axes of the created frame.
