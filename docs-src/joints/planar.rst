Planar
======

A planar joint moves a point in a plane and rotates a frame about the plane's normal, giving two translational and one rotational degree of freedom.

.. image:: ../img/planar.jpg
   :width: 400
   :alt: A planar joint: a point moving in a plane with a frame rotating about the plane's normal

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)
   ref_point_key | str | 'origin' | — | Start point from which the vector component of the joint is defined
   ref_frame_key | str | 'inertial' | — | Reference frame in which the translational and rotational displacement components are defined
   is_form | str | 'degree of freedom' | — | 'degree of freedom' makes the value a time-varying generalized coordinate; 'constant' fixes it at the given value.
   normal_axis | str | 'Z' | — | 'Z', 'Y', or 'X'. Represents the axis about which rotation is defined, and normal to the plane in which the translational coordinates are defined. If 'Z', then the (x, y) axis pair of the reference frame will be used for the translational DOFs, if 'Y' then (z, x), and if 'X' then (y, z)
   velocity_in | str | 'Created Frame' | — | 'Reference Frame' or 'Created Frame'
   initial_t0 | numeric | 0 | m | Initial value in the 0th translational coordinate
   initial_t1 | numeric | 0 | m | Initial value in the 1st translational coordinate
   initial_r | numeric | 0 | rad | Initial value for rotation
   rate_t0 | numeric | 0 | m/s | Initial speed in the 0th translational coordinate
   rate_t1 | numeric | 0 | m/s | Initial speed in the 1st translational coordinate
   rate_r | numeric | 0 | rad/s | Initial speed for rotation
   kt0 | numeric | 0 | N/m | Stiffness in the 0th translational coordinate
   kt1 | numeric | 0 | N/m | Stiffness in the 1st translational coordinate
   kr | numeric | 0 | N·m/rad | Stiffness for rotation
   ct0 | numeric | 0 | N·s/m | Damping in the 0th translational coordinate
   ct1 | numeric | 0 | N·s/m | Damping in the 1st translational coordinate
   cr | numeric | 0 | N·m·s/rad | Rotational damping
   equilibrium_t0 | numeric | 0 | m | Equilibrium distance in the 0th translational coordinate
   equilibrium_t1 | numeric | 0 | m | Equilibrium distance in the 1st translational coordinate
   equilibrium_r | numeric | 0 | rad | Equilibrium angle

Equations
---------

For ``normal_axis = 'Z'``, the point moves in the x-y plane of the reference frame and the frame rotates by θ about z:

.. math::

   \mathbf{r}_{B/A} = t_0\,\mathbf{e}_x + t_1\,\mathbf{e}_y

Optional spring-damper forces and torque:

.. math::

   F_i = -k_{t,i}\,(t_i - t_{e,i}) - c_{t,i}\,\dot{t}_i, \qquad \tau = -k_r\,(\theta - \theta_e) - c_r\,\dot{\theta}

Sign conventions & notes
------------------------

* ``is_form`` is ``'degree of freedom'`` (the value is a time-varying coordinate that the simulation solves for) or ``'constant'`` (the value is fixed).
* ``normal_axis`` is ``'X'``, ``'Y'`` or ``'Z'``. The two translations are in the plane perpendicular to it.
* ``velocity_in`` is ``'Reference Frame'`` or ``'Created Frame'`` and sets the frame in which the translational speeds are measured.
