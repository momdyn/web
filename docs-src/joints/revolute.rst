Revolute
========

A revolute joint is a hinge: it rotates a frame about one axis that is fixed in a reference frame. It adds one rotational degree of freedom.

.. image:: ../img/revolute.jpg
   :width: 400
   :alt: A revolute joint: a frame rotating about one axis of the reference frame

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)
   ref_point_key | str | 'origin' | — | Point at which the joint is displayed
   ref_frame_key | str | 'inertial' | — | Reference frame in which the components of the rotation axis are defined
   is_form | str | 'degree of freedom' | — | 'degree of freedom' makes the value a time-varying generalized coordinate; 'constant' fixes it at the given value.
   motion_axis | str | '+Z' | — | Axis in which the rotational motion is defined
   value | numeric | 0 | rad | Initial value for the generalized coordinate
   rate | numeric | 0 | rad/s | Initial value for the generalized speed
   k | numeric | 0 | N·m/rad | Spring constant
   c | numeric | 0 | N·m·s/rad | Damping constant
   equilibrium | numeric | 0 | rad | Equilibrium angle

Equations
---------

Optional spring-damper torque about the axis, restoring toward the equilibrium angle θ\_e:

.. math::

   \tau = -k\,(\theta - \theta_e) - c\,\dot{\theta}

Sign conventions & notes
------------------------

* ``is_form`` is ``'degree of freedom'`` (the value is a time-varying coordinate that the simulation solves for) or ``'constant'`` (the value is fixed).
* ``motion_axis`` is ``'+X'``, ``'-X'``, ``'+Y'``, ``'-Y'``, ``'+Z'`` or ``'-Z'``. Positive θ follows the right-hand rule about the chosen axis, so ``'-Z'`` reverses the direction.
* ``ref_point_key`` only sets where the joint is drawn. It does not change the physics. In the pendulum tutorial, ``value = 1`` sets the initial angle θ\_E to 1 rad.
