Revolute
========

A revolute joint creates a frame that is rotated relative to an existing frame about a motion axis defined in a specified reference frame. An optional rotational stiffness, damping, and equilibrium angle can be used to include rotational spring-damper physics in the joint.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)

.. param:: ref_point_key
   :type: str

   Point at which the joint is displayed

.. param:: ref_frame_key
   :type: str

   Reference frame in which the components of the rotation axis are defined

.. param:: motion_axis
   :type: str

   Axis in which the rotational motion is defined

.. param:: value
   :type: numeric

   Initial value for the generalized coordinate

.. param:: rate
   :type: numeric

   Initial value for the generalized speed

.. param:: k
   :type: numeric

   Spring constant

.. param:: c
   :type: numeric

   Damping constant

.. param:: equilibrium
   :type: numeric

   Equilibrium angle
