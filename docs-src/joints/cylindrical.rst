Cylindrical
===========

A cylindrical joint slides a point along an axis and rotates a frame about that same axis, giving one translational and one rotational degree of freedom.

.. image:: ../img/cylindrical.jpg
   :width: 400
   :alt: A cylindrical joint: a point sliding along an axis while a frame rotates about the same axis

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)
   ref_point_key | str | 'origin' | — | Start point from which the vector component of the joint is defined
   ref_frame_key | str | 'inertial' | — | Reference frame in which the translational and rotational displacement components are defined
   is_form | str | 'degree of freedom' | — | 'degree of freedom' makes the value a time-varying generalized coordinate; 'constant' fixes it at the given value.
   motion_axis | str | '+X' | — | '+X', '-X', '+Y', '-Y', '+Z', or '-Z', represents the axis in which rotation and translation are defined
   initial_t | numeric | 0 | m | Initial value in the translational coordinate
   initial_r | numeric | 0 | rad | Initial value for rotation
   rate_t | numeric | 0 | m/s | Initial speed in the translational coordinate
   rate_r | numeric | 0 | rad/s | Initial speed for rotation
   kt | numeric | 0 | N/m | Stiffness in the translational coordinate
   kr | numeric | 0 | N·m/rad | Stiffness for rotation
   ct | numeric | 0 | N·s/m | Damping in the translational coordinate
   cr | numeric | 0 | N·m·s/rad | Rotational damping
   equilibrium_t | numeric | 0 | m | Equilibrium distance in the translational coordinate
   equilibrium_r | numeric | 0 | rad | Equilibrium angle

Equations
---------

Position along the unit vector a of the motion axis, with rotation θ about the same axis:

.. math::

   \mathbf{r}_{B/A} = t\,\hat{\mathbf{a}}

Optional spring-damper force and torque:

.. math::

   F = -k_t\,(t - t_e) - c_t\,\dot{t}, \qquad \tau = -k_r\,(\theta - \theta_e) - c_r\,\dot{\theta}

Sign conventions & notes
------------------------

* ``is_form`` is ``'degree of freedom'`` (the value is a time-varying coordinate that the simulation solves for) or ``'constant'`` (the value is fixed).
* ``motion_axis`` is ``'+X'``, ``'-X'``, ``'+Y'``, ``'-Y'``, ``'+Z'`` or ``'-Z'``. A minus sign reverses the positive direction of both the translation and the rotation.
