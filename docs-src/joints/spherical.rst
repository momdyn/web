Spherical
=========

A spherical joint is a ball joint: it lets a frame take any orientation relative to another, with three rotational degrees of freedom.

.. image:: ../img/spherical.jpg
   :width: 400
   :alt: A spherical joint: a frame that can take any orientation relative to the reference frame

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)
   ref_point_key | str | 'origin' | — | Start point from which the vector component of the joint is defined
   ref_frame_key | str | 'inertial' | — | Reference frame in which the translational and rotational displacement components are defined
   is_form | str | 'degree of freedom' | — | 'degree of freedom' makes the value a time-varying generalized coordinate; 'constant' fixes it at the given value.
   rotation_sequence | str | 'ZYX' | — | 'ZYX', 'XYZ', 'ZXZ', 'ZYZ', 'XYX', or 'XZX', represents the Euler angle sequence used for defining equivalent initial quaternion states
   use_quaternion | bool | True | — | TODO
   initial_r0 | numeric | 0 | rad | Initial value for the 0th rotation angle in the Euler sequence
   initial_r1 | numeric | 0 | rad | Initial value for the 1st rotation angle in the Euler sequence
   initial_r2 | numeric | 0 | rad | Initial value for the 2nd rotation angle in the Euler sequence
   rate_r0 | numeric | 0 | rad/s | Initial value for angular rotation rate about the x-axis of the created frame
   rate_r1 | numeric | 0 | rad/s | Initial value for angular rotation rate about the y-axis of the created frame
   rate_r2 | numeric | 0 | rad/s | Initial value for angular rotation rate about the z-axis of the created frame
   kr0 | numeric | 0 | N·m/rad | Stiffness corresponding to the 0th rotation angle

Equations
---------

Orientation is tracked with a unit quaternion, which avoids the singularities of Euler angles:

.. math::

   q_0^2 + q_1^2 + q_2^2 + q_3^2 = 1

Sign conventions & notes
------------------------

* ``is_form`` is ``'degree of freedom'`` (the value is a time-varying coordinate that the simulation solves for) or ``'constant'`` (the value is fixed).
* ``initial_r0``, ``initial_r1`` and ``initial_r2`` give the starting orientation as an equivalent Euler angle sequence (``rotation_sequence``), which MOMDYN converts to the initial quaternion.
* The ``rate_r*`` values are the initial angular velocity components about the axes of the created frame.
