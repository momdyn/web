DCM Sensor
==========

A direction cosine matrix (DCM) sensor records the orientation of one frame relative to another as the nine entries of a rotation matrix.

.. diagram:: A DCM sensor: the rotation matrix between a sensed frame and a reference frame

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   frame_key | str | 'inertial' | — | The frame whose orientation is sensed.
   ref_frame_key | str | 'inertial' | — | The frame that the orientation is measured relative to.

Equations
---------

The components of a vector in the sensed frame B follow from its components in the reference frame A:

.. math::

   \{\mathbf{v}\}_B = {}^{B}C^{A}\,\{\mathbf{v}\}_A

Sign conventions & notes
------------------------

* The sensor adds nine time series, named R00 to R22 for the rows and columns of the matrix.
* For an orthogonal matrix the inverse is the transpose, so the matrix from A to B is the transpose of the matrix from B to A.
