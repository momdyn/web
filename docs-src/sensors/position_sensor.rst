Position Sensor
===============

A position sensor records where one point is relative to another point, in the axes of a chosen frame.

.. diagram:: A position sensor: the vector from a reference point to a sensed point, with components in a frame

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   point_key | str | 'origin' | — | The point whose position is sensed.
   ref_point_key | str | 'origin' | — | The point that the sensed position is measured relative to.
   ref_frame_key | str | 'inertial' | — | The frame that the sensed position is expressed in.

Equations
---------

The sensed quantity is the position vector from the reference point Q to the point P, resolved in the axes of frame F:

.. math::

   \{\mathbf{r}_{P/Q}\}_F = \begin{bmatrix} x \\ y \\ z \end{bmatrix}

Sign conventions & notes
------------------------

* The sensor adds three time series (x, y and z) to the simulation output.
* A real counterpart is a linear variable differential transformer (LVDT). The simulated sensor has none of its range or contact limits.
