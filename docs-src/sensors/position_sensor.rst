Position Sensor
===============

A position sensor records the position of one point relative to a reference point, expressed in a reference frame.

Keyword arguments
-----------------

.. param:: point_key
   :type: str

   The point whose position is sensed.

.. param:: ref_point_key
   :type: str

   The point that the sensed position is measured relative to.

.. param:: ref_frame_key
   :type: str

   The frame that the sensed position is expressed in.
