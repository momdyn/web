Velocity Sensor
===============

A velocity sensor records how fast a point is moving, in the axes of a chosen frame.

.. diagram:: A velocity sensor: the velocity vector of a point, with components in a frame

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   point_key | str | 'origin' | — | The point whose velocity is sensed.
   ref_frame_key | str | 'inertial' | — | The frame that the sensed velocity is expressed in.

Equations
---------

The sensed quantity is the velocity of the point P, resolved in the axes of frame F:

.. math::

   \{\mathbf{v}_P\}_F = \begin{bmatrix} v_x \\ v_y \\ v_z \end{bmatrix}
