Rate Gyro
=========

A rate gyro records the angular velocity of a frame expressed in a reference frame.

Keyword arguments
-----------------

.. param:: frame_key
   :type: str

   The frame whose angular velocity is sensed.

.. param:: ref_frame_key
   :type: str

   The frame that the sensed angular velocity is expressed in.
