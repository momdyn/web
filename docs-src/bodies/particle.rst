Particle
========

A particle is a point mass: mass concentrated at one point, with no rotational inertia.

.. image:: ../img/particle.jpg
   :width: 400
   :alt: A particle: a green and black sphere marking a point mass attached to a point

Parameters
----------

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

.. params::

   name | str | None | — | Key to be used when referencing this particle.
   ref_point_key | str | 'origin' | — | Key of the point to which this particle is fixed.
   mass | numeric | 0 | kg | Mass to be assigned to this particle.
   color | str | 'Green' | — | Color of the body in the diagram view (default Green). It does not affect the physics.

Equations
---------

The inertial force of a particle of mass m with acceleration a, and its weight in uniform gravity g:

.. math::

   \mathbf{F}^{*} = -m\,\mathbf{a}, \qquad \mathbf{F}_g = m\,\mathbf{g}

Sign conventions & notes
------------------------

* MOMDYN creates a parameter for the mass, named ``m_`` plus the particle name (for a particle named ``bob``, the symbol is m\_bob).
* ``color`` sets the color drawn in the diagram and does not change the physics. Options: Black, Gray, White, Red, Brown, Orange, Yellow, Mint, Green (default), Cyan, Blue, Teal, Pink, Indigo or Purple.
