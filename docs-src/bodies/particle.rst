Particle
========

A particle is a mass that is fixed to a point, with no inertia tensor.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Key to be used when referencing this particle.

.. param:: ref_point_key
   :type: str

   Key of the point to which this particle is fixed.

.. param:: mass
   :type: numeric

   Mass to be assigned to this particle.

Returns
-------

``str``: Message describing the particle.
