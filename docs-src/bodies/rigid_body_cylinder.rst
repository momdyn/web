Rigid Body Cylinder
===================

A rigid body cylinder is a circular rod of uniform density. The cylinder has length defined in the X-axis, and radius for the Y- and Z-axes, where (X, Y, Z) are the basis vectors of the body fixed frame.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Key to be used when referencing this cylinder.

.. param:: ref_point_key
   :type: str

   Key of the point to which this cylinder is attached, either at its CG, aft, or forward ends.

.. param:: ref_frame_key
   :type: str

   Key of the frame to which this cylinder orientation is defined.

.. param:: density
   :type: numeric

   Uniform density of this cylinder.

.. param:: length
   :type: numeric

   Dimension of this cylinder in the X-axis of the body-fixed frame.

.. param:: radius
   :type: numeric

   Dimension of this cylinder in the Y- and Z-axis of the body-fixed frame.

.. param:: attach_to
   :type: str

   CG, fore, or aft

Returns
-------

``str``: Message about the created cylinder
