General Rigid Body
==================

A general rigid body has its center of gravity (CG) located at a user-specified point and orientation defined in a specified frame, a fixed mass, and specified inertia tensor.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Key to be used when referencing this body.

.. param:: ref_point_key
   :type: str

   Key of the point at which this body's CG is located.

.. param:: ref_frame_key
   :type: str

   Key of the frame to which this body orientation is defined.

.. param:: mass
   :type: numeric

   Mass of this body.

.. param:: ixx
   :type: numeric

   Moment of inertia (MOI) of this body defined relative to its CG about the reference frame's X-axis.

.. param:: iyy
   :type: numeric

   MOI of this body defined relative to its CG about the reference frame's Y-axis.

.. param:: izz
   :type: numeric

   MOI of this body defined relative to its CG about the reference frame's Z-axis.

.. param:: ixy
   :type: str

   Product of inertia (POI) of this body defined relative to its CG in the reference frame's X- and Y-axes.

.. param:: iyz
   :type: str

   POI of this body defined relative to its CG in the reference frame's Y- and Z-axes.

.. param:: izx
   :type: str

   POI of this body defined relative to its CG in the reference frame's Z- and X-axes.

Returns
-------

``str``: Message about the created body
