Rigid Body Cone
===============

A rigid body cone is a circular cone of uniform density. The cone has length defined in the X-axis, and radius for the Y- and Z-axes, where (X, Y, Z) are the basis vectors of the body fixed frame.

Keyword arguments
-----------------

.. param:: name
   :type: str

   Key to be used when referencing this cone.

.. param:: ref_point_key
   :type: str

   Key of the point to which this cone is attached, either at its CG, aft, or forward ends.

.. param:: ref_frame_key
   :type: str

   Key of the frame to which this cone orientation is defined.

.. param:: density
   :type: numeric

   Uniform density of this cone.

.. param:: length
   :type: numeric

   Dimension of this cone in the X-axis of the body-fixed frame.

.. param:: radius
   :type: numeric

   Dimension of this cone in the Y- and Z-axes of the body-fixed frame.

.. param:: attach_to
   :type: str

   CG, fore, or aft

Returns
-------

``str``: Message about the created cone
