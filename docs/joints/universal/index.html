Universal

On this page

On this page

  • Parameters
  • Equations
  • Sign conventions & notes
  • Related

A universal joint orients a frame with two successive rotation angles, giving two rotational degrees of freedom, like a drive-shaft coupling.

Parameters

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

NameTypeDefaultUnitsDescription
namestrNone—Name given to the joint, default is uppercase characters in alphabetical order (A, B, C, ...)
ref_point_keystr'origin'—Start point from which the vector component of the joint is defined
ref_frame_keystr'inertial'—Reference frame in which the translational and rotational displacement components are defined
is_formstr'degree of freedom'—'degree of freedom' makes the value a time-varying generalized coordinate; 'constant' fixes it at the given value.
rotation_pairstr'YX'—'XY', 'YX', 'YZ', 'ZY', 'ZX', or 'XZ', represents a two angle rotation sequence
initial_r0numeric0radInitial value for the 0th rotation angle in the Euler sequence
initial_r1numeric0radInitial value for the 1st rotation angle in the Euler sequence
rate_r0numeric0rad/sInitial value for angular rotation rate of the 0th angle
rate_r1numeric0rad/sInitial value for angular rotation rate of the 1st angle Optional stiffness, damping, and equilibrium coefficients can be used to include rotational spring-damper physics in the joint.
kr0numeric0N·m/radStiffness corresponding to the 0th rotation angle in the Euler sequence
kr1numeric0N·m/radStiffness corresponding to the 1st rotation angle in the Euler sequence
cr0numeric0N·m·s/radDamping corresponding to the angular rotation rate about the x-axis of the created frame
cr1numeric0N·m·s/radStiffness corresponding to the angular rotation rate about the y-axis of the created frame
equilibrium_r0numeric0radEquilibrium corresponding to the 0th rotation angle in the Euler sequence
equilibrium_r1numeric0radEquilibrium corresponding to the 1st rotation angle in the Euler sequence

Equations

For rotation_pair = 'YX', with angles θ₀ and θ₁, the frame orientation is:

ACB=Ry(θ0) Rx(θ1){}^{A}C^{B} = R_y(\theta_0)\,R_x(\theta_1)ACB=Ry​(θ0​)Rx​(θ1​)

Optional spring-damper torque for each angle i = 0, 1:

τi=−kr,i (θi−θe,i)−cr,i θ˙i\tau_i = -k_{r,i}\,(\theta_i - \theta_{e,i}) - c_{r,i}\,\dot{\theta}_iτi​=−kr,i​(θi​−θe,i​)−cr,i​θ˙i​

Sign conventions & notes

  • is_form is 'degree of freedom' (the value is a time-varying coordinate that the simulation solves for) or 'constant' (the value is fixed).

  • rotation_pair is one of 'XY', 'YX', 'YZ', 'ZY', 'ZX' or 'XZ'. The second rotation is about an axis of the frame produced by the first.
