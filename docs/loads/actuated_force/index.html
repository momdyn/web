Actuated Force

On this page

On this page

  • Parameters
  • Equations
  • Sign conventions & notes
  • Related

An actuated force acts with equal and opposite magnitude on two points, like a linear actuator pushing two parts of a mechanism apart.

Parameters

Units are shown in SI (m, kg, s, N, rad). MOMDYN does not enforce units, so any consistent set works, but angles are always in radians.

NameTypeDefaultUnitsDescription
namestrNone—Name given to the force.
ref_frame_keystr'inertial'—Reference frame in which the vector components of the force are defined.
start_pointstr'origin'—First point upon which the force acts.
end_pointstr'origin'—Second point upon which the force acts, with negative magnitude.
forcenumeric0NForce magnitude.
xnumeric0—X-component of the vector aligned with the force.
ynumeric0—Y-component of the vector aligned with the force.
znumeric0—Z-component of the vector aligned with the force.

Equations

Force on the start point and on the end point, with magnitude F along the unit vector u:

Fstart=F u^,Fend=−F u^\mathbf{F}_{\text{start}} = F\,\hat{\mathbf{u}}, \qquad \mathbf{F}_{\text{end}} = -F\,\hat{\mathbf{u}}Fstart​=Fu^,Fend​=−Fu^

Sign conventions & notes

  • The direction is set by the components x, y and z in ref_frame_key. TODO: confirm that the components are normalized, so that only force (or moment) sets the magnitude.

  • Because the two forces are equal and opposite, an actuated force changes the internal motion of a mechanism but not its net momentum.
